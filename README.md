# 공학 일반 출석부

고3 선택과목 '공학 일반' 2개 분반(51명) 출석체크 웹앱입니다. 휴대폰에서 쓰는 것을 기준으로 만들었습니다.

## 바로 써 보기

- **PC에서 확인**: `index.html`을 더블클릭하면 열립니다. 이때는 오프라인 캐시(서비스 워커)만 동작하지 않습니다.
- **로컬 서버**: 이 폴더에서 `npx serve .`를 실행한 뒤 표시되는 주소로 접속합니다.
- **휴대폰에서 쓰기**: HTTPS 주소가 있어야 홈 화면에 설치할 수 있습니다. Firebase Hosting 배포는 [docs/firebase.md](docs/firebase.md)를 참고하십시오.

## 쓰는 법

| 동작 | 결과 |
| --- | --- |
| 학생 카드 누르기 | 출석 → 지각 → 결과 → 출석 순으로 바뀝니다(사유 기본값: 미인정) |
| 학생 카드 길게 누르기 | 6가지 상태와 사유(질병·미인정·기타), 메모를 고르는 시트가 열립니다 |
| 전원 출석으로 기록 | 예외 학생이 없을 때 이 수업을 출석으로 확정합니다 |
| 토스트의 되돌리기 | 방금 바꾼 학생을 이전 상태로 되돌립니다 |
| 설정 → 주간 시간표 | 칸을 누를 때마다 1분반 → 2분반 → 비움으로 바뀝니다. 앱을 열면 현재 수업이 자동으로 선택됩니다 |

## 파일 구조

```
index.html               화면 4개(출석부·통계·내보내기·설정)
css/style.css            CNM 레트로 테마
js/roster.js             초기 명렬표·교시 시간
js/store.js              저장소(현재: 기기 localStorage)
js/firebase-store.js     Firebase 저장소 뼈대(연결 시 사용)
js/app.js                화면 로직
sw.js, manifest.webmanifest   PWA(오프라인·홈 화면 설치)
assets/img/              생성 이미지가 들어갈 자리(없으면 이모지로 대체)
docs/image-prompts.md    이미지 생성 프롬프트
```

## 명렬표와 개인정보

배포본에는 **가명 명렬표**(가학생01~29, 나학생01~22)만 들어 있습니다. 실명은 저장소에 올리지 않습니다.

- 실명 명렬표는 `js/roster.local.js`와 `private/` 폴더에만 있고, `.gitignore`로 업로드에서 빠집니다.
- 이 PC에서 `index.html`을 열면 실명 명렬표가 자동으로 쓰입니다.
- 휴대폰(배포 주소)에서는 `private/명렬표_실명_불러오기용.json`을 휴대폰으로 옮긴 뒤 **내보내기 → 백업 파일 불러오기**로 한 번 넣으십시오. 이후 실명은 그 휴대폰 안에만 저장됩니다.

## 데이터

- 지금은 기기 브라우저에만 저장됩니다. 기기를 바꾸기 전에는 **내보내기 → 백업 파일 저장**을 하십시오.
